# 陽明高中校園安全總覽

一頁式互動校園安全地圖，可供校安與總務人員標記校園安全問題。

## 使用方式

直接開啟 `index.html`，或以靜態網站伺服器提供此資料夾。

- 依安全圖層新增不同顏色與縮寫的圖釘
- 開啟移動模式後拖曳圖釘調整位置
- 記錄提出人員、聯絡方式、原因、改善建議與處理進度
- 圖釘資料儲存在目前裝置的瀏覽器中，不會自動上傳到伺服器

## 檔案

- `index.html`：頁面結構
- `styles.css`：視覺樣式
- `app.js`：互動功能與本機資料儲存
- `assets/campus-map-v3-no-track.png`：校園配置底圖
