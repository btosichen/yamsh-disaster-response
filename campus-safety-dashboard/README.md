# 陽明高中校園安全總覽

一頁式互動校園安全地圖，可供校安與總務人員標記校園安全問題。

## 使用方式

直接開啟 `index.html`，或以靜態網站伺服器提供此資料夾。

- 依安全圖層新增不同顏色與縮寫的圖釘
- 開啟移動模式後拖曳圖釘調整位置
- 記錄提出人員、聯絡方式、原因、改善建議與處理進度
- 開啟後可直接儲存，連線異常時未同步圖釘暫存於本機
- 圖釘與改善紀錄逐筆同步到 Google 試算表；原本機圖釘可手動匯入
- 共用讀取與刪除密碼由 GAS 伺服器驗證；儲存不需密碼；設定方式見 [gas/README.md](gas/README.md)

## 檔案

- `index.html`：頁面結構
- `styles.css`：視覺樣式
- `app.js`：互動功能與本機資料儲存
- `assets/campus-map-v3-no-track.png`：校園配置底圖
- `assets/archive/`：設計過程保留的舊版校園底圖
- `.openai/hosting.json`：靜態網站部署設定

## 後方建築補充

依 115學年度班級教室平面圖（115.08.05版），在立志樓後方補上左側漾泉館（溫水游泳池）及右側悅聞樓（專科教室大樓）。`assets/rear-buildings.svg` 為透明向量補圖，沿用原底圖尺寸，不改動既有圖釘的百分比座標。建築輪廓為位置示意。

開啟頁面即自動載入大家共用的圖釘位置，無痕與不同裝置也能看到；每30秒更新，詳細紀錄與刪除保留密碼驗證。
