## 首次啟用

1. 從指定試算表的「擴充功能 → Apps Script」開啟專案。`Code.gs` 已提供完整程式。
2. 執行 `install`，完成 Google 授權。回到該次執行所開啟的試算表視窗，輸入原先的管理密碼並確認。若看不到視窗，從自己的瀏覽器開啟上述專案重新執行 `install`，再回到同一瀏覽器的試算表。
3. 程式會建立「校園安全圖釘」與「操作紀錄」分頁，保留原有「工作表1」及其他資料。密碼僅以加鹽雜湊存於 Apps Script 的指令碼屬性，不寫入工作表或網站原始碼。
4. 按「部署 → 新增部署作業 → 網頁應用程式」，執行身分選自己，存取權選「任何人」。這只開放 API 入口；新增與修改可直接寫入；讀取、刪除與清除需要密碼。不必公開共用試算表。
5. 複製 `/exec` 網址，網站已預設部署網址；儲存不需密碼，按「讀取共用資料（需密碼）」才輸入管理密碼。
6. 在原本有圖釘的瀏覽器，按「匯入原本機圖釘」。這是新增匯入，不會覆蓋其他人的資料；重複匯入會建立重複圖釘。

## 日常使用

- 開啟網站後新增、移動與「儲存改善紀錄」皆會逐枚同步；上方顯示「已同步至共用試算表」才代表服務已確認寫入。
- 儲存不需密碼；每次按「讀取共用資料」都要重新輸入管理密碼。網站不會在重載時自動讀取共用資料。
- 按「讀取共用資料（需密碼）」讀取其他同仁的變更。多人同時修改同一枚圖釘會阻擋舊版本，不會整張覆蓋。
- 網路異常時未同步資料留在本機，可按「重試同步」。若有修改衝突，可按「讀取共用資料（需密碼）」，確認後會先下載本機備份再採用共用版本。
- 刪除在伺服器端驗證密碼，採用註記刪除；原圖釘及快照留在試算表，舊版資料不能重新上傳把已刪除圖釘復活。
- 未連線時，未同步資料保留在本機；必須看到同步完成才表示共用資料已更新。
- 請避免直接改動「圖釘ID」「版本」「完整資料」等儲存欄位；日常編輯請使用網站。

## 管理密碼設定與網頁保護

若服務顯示尚未初始化，請重新整理試算表，選「校園安全管理 → 設定讀取／刪除密碼」，在遮罩設定視窗輸入管理密碼後按「儲存密碼並啟用讀取、刪除」。只有指定管理者可儲存設定，密碼以加鹽雜湊保存在指令碼屬性。設定成功後無須重新部署，即可使用原服務網址。

公開 HTML 已移除縮排，前端不再包含密碼雜湊或驗證演算法；前端壓縮僅減少可讀性，並非加密或權限控制。讀取、刪除與清除的保護由 GAS 伺服器提供。

一次性修復也可由已授權的 Google Sheets 連接工具，建立私有暫存設定頁 `_管理密碼初始化`，只寫入 `PASSWORD_SALT` 與 `PASSWORD_HASH`（64字元十六進位值）。GAS 第一次驗證時會轉存到指令碼屬性並移除該暫存頁。此流程不將明文密碼寫入試算表、GitHub 或公開網頁。

刪除前，網站會使用當次輸入的密碼讀取最新版圖釘與資料版本。若該圖釘已有更新，會顯示更新時間並要求確認；確認期間若再次有其他人更新，伺服器仍會阻擋刪除，按一次重試即可重新確認，不必整頁重載。刪除成功後會同時移除相同 ID 的舊版本機副本，避免重新整理後再次出現。
